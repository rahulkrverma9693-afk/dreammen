# 🌹 DreamGirl & DreamMen Family Salon & Spa — V2 POS System

A modern, full-stack monorepo application for salon & spa management, smart POS billing, online appointment bookings, customer CRM, staff management, inventory tracking, and reports.

## 🚀 Technology Stack
- **Frontend**: React, Vite, TypeScript, TailwindCSS, React Query, Lucide Icons
- **Backend**: Node.js, Express, Prisma ORM, JWT Authentication
- **Database**: PostgreSQL (Supabase)

## 📁 Project Structure
```
dreamgitrl/
├── apps/
│   ├── frontend/   # React POS App & Public Online Booking (/book)
│   └── backend/    # Node.js Express API & Prisma ORM
├── docker-compose.yml
└── package.json
```

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Running Locally
```bash
# Install dependencies across monorepo
npm install

# Run frontend & backend dev servers concurrently
npm run dev
```

### URLs
- **Frontend App**: `http://localhost:5173`
- **Online Booking Portal**: `http://localhost:5173/book`
- **Backend API**: `http://localhost:5000/api`
